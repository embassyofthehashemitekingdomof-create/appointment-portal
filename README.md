# بوابة المواعيد — نسخة قاعدة بيانات حقيقية

هذه النسخة تستخدم Node.js + Express + SQLite. الحجز لا يُحفظ في المتصفح؛ يتم حفظه في قاعدة بيانات الخادم، لذلك يمكن الاستعلام عنه من جهاز آخر عند تشغيل الموقع على استضافة تدعم Node.js وملف قاعدة بيانات دائم.

## التشغيل محليًا
```bash
npm install
npm start
```
ثم افتح `http://localhost:3000`.

## الرفع على الاستضافة
ارفع المشروع إلى استضافة Node.js، واضبط أمر التشغيل `npm start`. يجب أن تكون قاعدة SQLite على Disk/Persistent Volume حتى لا تضيع البيانات عند إعادة تشغيل التطبيق.

## ملاحظة مهمة
GitHub مناسب لحفظ الكود، لكنه ليس مكان تشغيل قاعدة البيانات. لا تضع أسرار اتصال قاعدة البيانات داخل الواجهة الأمامية.
